# CodeAlpha Student Grade Tracker

## Project Description

Student Grade Tracker is a Java console-based application developed as part of the CodeAlpha Java Programming Internship.

The program allows the user to enter student names and their grades. It then calculates and displays the average, highest, and lowest grades along with a summary report.

## Features

- Add student names and grades
- Store student information using ArrayList
- Calculate average grade
- Find highest grade
- Find lowest grade
- Display a complete student report
- Console-based user interface

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Scanner

## Project Structure

CodeAlpha_StudentGradeTracker/

- Student.java
- GradeTracker.java
- Main.java
- README.md

## How to Run

1. Open the project folder in VS Code.
2. Make sure Java is installed.
3. Open Main.java.
4. Click the Run button.
5. Enter the number of students.
6. Enter each student's name and grade.
7. The program will display the final report.

## Output

The program displays:

- Total number of students
- Average grade
- Highest grade
- Lowest grade
- Individual student details
